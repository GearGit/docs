Carry-forward and piping are two ways to reuse what a respondent has already told you. Carry-forward takes the options a respondent selected and turns them into the choice list for a later question. Piping inserts the text of an earlier answer directly into the wording of a later question or an ending screen. This page explains both features and walks you through setting them up.

## Carry-Forward

### What It Does

Carry-forward links the selected options from one question to the answer list of a later question. Only the items the respondent actually chose are shown as options in the destination question. Items they did not select are excluded.

**Practical example:** You ask "Which of the following social media platforms do you use?" and the respondent selects Instagram, LinkedIn, and TikTok. On a later question, "Which platform do you use most for work-related content?", only Instagram, LinkedIn, and TikTok appear as options. The full list of platforms is never shown again.

This keeps later questions relevant and reduces cognitive load for respondents.

### Setting Up Carry-Forward

<Steps>
  <Step title="Identify the source question">
    Make sure the source question (the one whose selected options you want to carry forward) is a multi-select or single-select question and appears earlier in the survey.

    ![A multi-select question listing social media platforms in the builder canvas](/images/placeholder.png)
  </Step>

  <Step title="Select the destination question">
    Click the later question where you want the carried-forward options to appear. Open the **Logic** tab in the right-hand panel.

    ![The destination question selected with the Logic tab open](/images/placeholder.png)
  </Step>

  <Step title="Enable carry-forward">
    In the **Answer options** section of the Logic tab, click **Carry forward from** and select the source question from the dropdown. The option list for the destination question is now driven by the respondent's earlier selections.

    ![The Carry forward from dropdown open, with the source question highlighted](/images/placeholder.png)
  </Step>

  <Step title="Add any fixed options if needed">
    You can append fixed options (such as "None of the above" or "Other") below the carried-forward list. These appear for every respondent regardless of what they selected earlier.
  </Step>

  <Step title="Preview the carry-forward">
    Open **Preview**, select a subset of options on the source question, and advance to the destination question to confirm only the selected items appear.

    ![Preview mode showing only the options selected on the earlier question appearing in the destination question](/images/placeholder.png)
  </Step>
</Steps>

## Piping

### What It Does

Piping inserts the text of an earlier answer into a question's wording, a block title, or an ending screen message. The inserted text changes for each respondent based on what they said.

**Practical example:** You ask "What is the name of your primary vendor?" and the respondent types "Acme Corp." A later question reads: "How satisfied are you with Acme Corp.'s support?" The vendor name is pulled in automatically, so every respondent sees a question tailored to their own answer.

Piping works with both open-text answers (inserting typed text) and selected option labels (inserting the label of the chosen option).

### Setting Up a Pipe

<Steps>
  <Step title="Identify the source answer">
    Make sure the question whose answer you want to pipe appears earlier in the survey. Note whether it is an open-text answer or a selected option, as both are supported.
  </Step>

  <Step title="Place your cursor in the destination text">
    Click on the destination question, block title, or ending screen message where you want the piped answer to appear. Place your cursor at the exact position where the text should be inserted.

    ![A question in edit mode with the cursor positioned in the text field](/images/placeholder.png)
  </Step>

  <Step title="Open the Insert variable menu">
    Click the **Insert variable** button in the text editor toolbar (it looks like a tag or curly-brace icon). A dropdown appears listing all pipeable sources from earlier in the survey.

    ![The Insert variable dropdown open in the question text editor toolbar](/images/placeholder.png)
  </Step>

  <Step title="Select the source answer">
    Choose the earlier question or answer you want to pipe. A placeholder chip is inserted into your text at the cursor position. This chip is replaced with the respondent's actual answer when they reach the question.

    ![A pipe token inserted into the question text, displayed as a highlighted chip](/images/placeholder.png)
  </Step>

  <Step title="Add a fallback value">
    In the token settings (click the token chip to open them), enter a fallback text. The fallback appears if the source question was skipped or left blank, for example "your vendor" instead of a blank space.
  </Step>

  <Step title="Preview the pipe">
    Open **Preview**, answer the source question, and advance to the destination to confirm the piped text appears correctly.
  </Step>
</Steps>

## Combining Both Features

Carry-forward and piping work well together. A common pattern is to carry forward options from a multi-select question and then pipe the label of each carried-forward item into the follow-up question text. If you are iterating over each carried-forward item one at a time, consider using a loop (see [Looping](/logic/looping)) in combination with carry-forward for a fully automated, per-item question set.

<Tip>
  Always set a fallback value on every pipe token. Without a fallback, a skipped source question leaves a blank space or broken phrase in your question text, which can confuse respondents.
</Tip>
