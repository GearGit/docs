The media library is a central store for every image and file you upload to your OnlineSurvey workspace. This page explains where to find it, how to upload files, how to insert images into your survey, and the storage limits that apply to each plan.

## Where to Find the Media Library

The media library is accessible from two places.

- **From the top navigation:** Click the **Media** icon in the left sidebar of any survey or from the main workspace dashboard to browse all uploaded files.
- **From within the builder:** Any time you add an image to a question or content block, a library picker opens, letting you choose an existing file or upload a new one without leaving your survey.

![The media library panel showing a grid of uploaded image thumbnails with file names below each one](/images/placeholder.png)

Files in the library are shared across all surveys in your workspace. An image uploaded for one survey can be reused in any other survey without uploading it again.

## Uploading Images and Files

<Steps>
  <Step title="Open the media library">
    Click the **Media** icon in the left sidebar, or click **+ Upload** if you are already inside the library panel.
  </Step>
  <Step title="Select files to upload">
    Click **Upload Files** and select one or more files from your device. You can also drag and drop files directly onto the library panel.

    Supported formats are: JPEG, PNG, GIF, WebP, and SVG for images. PDF files are also supported for use in content blocks.

    ![The upload drop zone in the media library with a dashed border and an upload icon in the centre](/images/placeholder.png)
  </Step>
  <Step title="Wait for processing">
    Each file is uploaded and processed immediately. A progress indicator appears next to each file. Once processing is complete, the file is available to insert into any survey.
  </Step>
  <Step title="Organise with folders (optional)">
    Use the **New Folder** button to create folders and keep your library tidy. Drag files into folders to organise them by campaign, project, or date.
  </Step>
</Steps>

<Note>
  There is no limit on the number of individual files you can upload, only on the total storage they consume. Storage limits are listed below.
</Note>

## Inserting an Image into a Question

You can add an image to most question types, either as a visual aid above the question text or as the answer options themselves (using the Image Tiles question type).

<Steps>
  <Step title="Select the question">
    Click the question on the canvas to open its settings panel.
  </Step>
  <Step title="Click the image slot">
    In the settings panel, click **Add Image** above the question text field. If the question type supports per-option images (such as Image Tiles), each answer choice also has its own image slot.

    ![The question settings panel with an Add Image button above the question text field](/images/placeholder.png)
  </Step>
  <Step title="Choose or upload a file">
    The media library picker opens. Click an existing image to insert it, or click **Upload** to add a new file from your device and insert it in one step.
  </Step>
  <Step title="Set the image display size">
    Use the size control that appears below the inserted image to choose Small, Medium, or Full Width. The canvas updates immediately so you can judge the proportions.
  </Step>
</Steps>

## Inserting an Image into a Content Block

Content blocks are non-question elements you can add between questions to display instructions, headers, or visuals.

<Steps>
  <Step title="Add a content block">
    In the builder, click **+ Add Question** and select **Content Block** from the picker. The block is added to the canvas.
  </Step>
  <Step title="Click the image slot inside the block">
    Content blocks have a dedicated image area. Click the image slot to open the media library picker.

    ![A content block on the canvas with an empty image slot and a text area below it](/images/placeholder.png)
  </Step>
  <Step title="Choose or upload your image">
    Select an existing file or upload a new one. The image appears inside the block at full width by default. Use the size controls to resize it.
  </Step>
</Steps>

## Storage Limits by Plan

| Plan | Storage included |
|---|---|
| **Free** | 100 MB |
| **Basic** | 5 GB |
| **Pro** | 50 GB |
| **Custom** | Negotiated with your account team |

You can see your current storage usage in the media library by clicking the **Usage** indicator at the bottom of the panel.

<Warning>
  When your workspace reaches its storage limit, you will not be able to upload new files until you delete existing ones or upgrade your plan. Existing surveys and images are not affected and will continue to work. To upgrade, visit your account settings or contact [support@onlinesurvey.ai](mailto:support@onlinesurvey.ai).
</Warning>

## Deleting Files from the Library

To delete a file, hover over it in the library grid and click the **Delete** icon. A confirmation prompt appears before the file is removed.

<Warning>
  Deleting an image from the library removes it from every survey where it is currently used. Respondents filling a published survey that references the deleted image will see a broken image placeholder. Check where a file is used before deleting it by clicking the file and viewing the **Used in** list.
</Warning>

## Replacing an Image

To swap an image for a newer version without updating every survey manually, click the file in the library and choose **Replace**. Upload the new file, and it will take the place of the old one in all surveys where it appears. The URL and file name stay the same so your published surveys are updated automatically.
