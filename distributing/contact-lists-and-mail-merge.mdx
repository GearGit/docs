Contact lists store the recipients for your email campaigns. You build a list by uploading a CSV file, and OnlineSurvey uses the column headers in that file as merge tokens so each recipient can receive a personalised email. This page explains how to prepare your file, upload a list, manage existing lists, and use merge tokens in your email body.

## What a Contact List Needs

A valid contact list is a CSV file with at least one column: the email address column. The header for that column must be `email` (lowercase). Every row below the header represents one recipient.

You can add as many additional columns as you like. Each column becomes a mail-merge token you can use in the email subject line or body. Common extra columns include `first_name`, `last_name`, `company`, and `job_title`, but you can name them anything that is useful to your study.

| email | first_name | company |
|-------|-----------|---------|
| alex@example.com | Alex | Acme Corp |
| jordan@example.com | Jordan | Beta Ltd |

<Note>
  Column headers must not contain spaces or special characters. Use underscores to separate words, for example `first_name` rather than `First Name`. Headers are case-sensitive in the merge token, so a header of `first_name` must be referenced as `{{first_name}}` in your email.
</Note>

## Upload a Contact List

<Steps>

  ### Open the Contact Lists Section

  Click **Distribute** in the top navigation bar of your survey editor, then click **Contact lists** in the left panel. Any lists you have already uploaded appear here.

  ![The Contact lists section in the Distribute tab showing an empty state with an Upload button](/images/placeholder.png)

  ### Start the Upload

  Click **Upload list**. A file picker dialog opens.

  ### Select Your CSV File

  Choose the CSV file from your computer and click **Open**. OnlineSurvey begins processing the file and shows a preview of the first few rows alongside the detected column headers.

  ![The upload preview showing the first three rows of the CSV and the detected column headers](/images/placeholder.png)

  ### Confirm the Email Column

  OnlineSurvey attempts to detect the email column automatically. If the detected column is correct, leave the selection as is. If the platform has identified the wrong column, use the dropdown to select the correct one.

  ### Name the List

  Give the list a descriptive name so you can identify it when setting up campaigns. You might include the audience type or the date of the upload, for example "Q2 Customer Panel" or "Event Attendees May 2025".

  ### Save the List

  Click **Save list**. OnlineSurvey validates every email address in the file and flags any rows where the address is malformed. You can download a report of flagged rows, correct them in your original file, and re-upload if needed.

  ![The upload summary showing 342 valid addresses and 3 flagged rows with a Download flagged rows link](/images/placeholder.png)

</Steps>

## Manage Existing Lists

In the Contact lists section, each saved list shows the name, upload date, total contact count, and the number of invalid addresses filtered out at upload. You can download the original file, delete the list, or upload a replacement file to the same list name.

<Warning>
  Deleting a contact list is permanent. If the list is attached to a scheduled campaign, you must detach it or cancel the campaign first. Deleting a list does not affect responses already collected from a previous send that used that list.
</Warning>

## Using Mail Merge Tokens

Mail merge lets you personalise each email using the data from your contact list. Every column header in your CSV becomes a token you can drop into the email subject or body.

The token format is double curly braces around the exact column header name: `{{first_name}}`, `{{company}}`, `{{job_title}}`. At send time, OnlineSurvey replaces each token with the value from the corresponding row in the list.

<Steps>

  ### Open or Create a Campaign

  Navigate to **Email campaigns** in the Distribute tab and open an existing campaign or click **New campaign**.

  ### Type a Token in the Subject or Body

  Click in the email subject field or the email body editor. Type `{{` followed by the column header name and `}}`. For example, to greet each recipient by first name, type `Hi {{first_name}},` at the start of the email body.

  ![The email body editor showing "Hi {{first_name}}, we would love your feedback" with the merge token highlighted](/images/placeholder.png)

  ### Preview the Merge

  Click **Preview merge** to see how the email will appear for a specific recipient. A dropdown lets you select any row from your contact list as the preview subject. Check that the tokens resolve correctly and that the email reads naturally.

  ![The merge preview panel showing the email as it will appear for a contact named "Alex" at "Acme Corp"](/images/placeholder.png)

  ### Check for Missing Values

  If a row in your contact list has a blank cell for a column referenced in a token, that token will be replaced with an empty string, leaving a gap in the sentence. Review your list for blank cells in any column you plan to use as a merge token before sending.

</Steps>

<Tip>
  To add a fallback for contacts with a missing value, restructure your sentence to work without the token or clean the list before uploading. For example, use "Hi there," as your salutation if first names are not reliably available for every contact.
</Tip>

## The Survey Link Token

Every campaign email must include `{{survey_link}}` somewhere in the body. This token is replaced at send time with each recipient's unique, trackable survey URL. The unique URL allows OnlineSurvey to attribute each response and each click back to the individual contact in your delivery tracking view.

Because the link is unique per recipient, sharing it with someone else would attribute their responses to the original contact. Remind recipients to fill in the survey themselves rather than forwarding the email.
